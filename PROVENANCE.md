# Provenance

ThreadTruth Studio was created as a sanitized snapshot of the deeply developed private Skill `clothing-portrait-studio` at commit `1eb29ad`.

The public repository starts with a new Git history. The snapshot process copied only runtime instructions, references, 24 style packs, the canvas checker, development evals, and selected validation tools. It intentionally excluded private Git history, absolute workstation paths, personal email addresses, customer material, private logs, historical generated images, and evidence with unresolved licensing.

Historical verification claims do not automatically transfer to the public Beta. The public project remains `DRAFT` until its rights-cleared cases and reproducible Beta evidence are recorded here.
