服饰 AI 影棚 / AI Fashion Studio

为服饰品牌、电商团队和设计师制作服饰模特展示图。支持单件或完整套装识别、24 种风格选择，以及棚拍、场景或混合方向。默认在 Codex 使用原生生图；ChatGPT 网页是明确选择后的可选转交路线，自动执行依赖宿主浏览器工具。

Create model images from a garment or coordinated outfit. Choose among 24 styles and studio, location or hybrid scenes. Codex is the default route; ChatGPT web handoff requires an explicit choice and appropriate host tools.

完整能力与生成指令 / Full capabilities

准备照片 / Prepare your photos

最低一张清晰、有权使用的真实服饰照片即可开始识别；推荐补充正面、背面和关键细节。完整套装需看清各层衣物及鞋包配饰。不同颜色、不同商品分开确认；看不到的细节不应被当作已知事实。

Start recognition with one clear, authorized garment photo. Front, back and detail views help. For outfits, show layers and accessories. Keep product variants separate; hidden details remain uncertain.

不要上传凭据、账号截图或未经授权的客户素材。无图时可先做下面的缺图检查；没有适当服饰照片，就把识别与生图项记为未测试。
Do not upload credentials or unauthorized customer material. With no suitable photo, test the missing-input path and leave image steps untested.

安装预发布版 / Install the prerelease

本轮面向 macOS、Python 3、支持 codex plugin add 的 Codex CLI。为 ZIP、解压目录、源、缓存和一份旧版备份预留约 300 MB；网络和操作熟悉度会影响安装时间，请记录实际耗时。无需管理员权限或额外 API key。首次识别不生图；后续生成需账号图片能力、额度及另行授权。

This trial targets macOS, Python 3 and a Codex CLI supporting plugin installation. Reserve about 300 MB and record the actual setup time. No administrator permission or extra API key is needed. New-host discovery and other operating systems are unverified.

先检查工具 / Check tools first:

python3 --version
codex --version
codex plugin add --help

使用本轮交付的本地 ZIP 与匹配校验文件；公开 beta.11 Release 不包含此候选。先进入存放这两个文件的目录，再执行：

shasum -a 256 -c threadtruth-studio-1.0.0-beta.11+model-reuse.20261004.flow2.zip.sha256 &&
unzip threadtruth-studio-1.0.0-beta.11+model-reuse.20261004.flow2.zip &&
cd threadtruth-studio-1.0.0-beta.11+model-reuse.20261004.flow2

先校验，再解压；失败即停。使用空目录，避免覆盖旧解压文件。校验值需来自可信渠道，checksum 本身不能认证发布者。
Verify before extraction, stop on failure and avoid overwriting an existing extraction. Obtain the checksum through a trusted channel; it does not independently authenticate the publisher.

首次安装 / New installation:

python3 install-local.py

预检不写入。确认路径后，执行 / Preview writes nothing. After checking paths:

python3 install-local.py --apply

注册将文件复制到用户主目录的 plugins/threadtruth-studio，更新 .agents/plugins/marketplace.json 并保留其他插件记录；它本身不会启用插件。执行输出中 Next: 后的完整命令，再查看 codex plugin list --json 的已安装列表。默认示例为 codex plugin add threadtruth-studio@personal --json，实际 selector 以安装器为准。

Registration copies the source and updates your personal marketplace without enabling it. Run the exact printed Next: command, then inspect the installed list. A fresh registration keeps 1.0.0-beta.11+model-reuse.20261004.flow2; replacement rewrites the entire build identifier to 1.0.0-beta.11+codex.<timestamp>-<id>. Verify runtime SHA-256 hashes against the supplied candidate manifest as well as the display name 裁光 · Caiguang. Existing installations must use the upgrade steps below.

边界与案例 / Limits and examples

适用于服饰人像与电商展示，不用于非服饰商品、纯文字概念、CAD 合体模拟、API 集成或无人值守交付。有明确同意和使用权时可沿用真人身份参考，但不承诺精确身份复制。不保证小字、Logo、隐藏结构或合体效果。图片必须对照源图与人工验收，不能由文件存在推断可商用。

For apparel portraits, not non-apparel products, text-only concepts, CAD fit, API integration or unattended delivery. Consented identity references are supported; exact identity reproduction is not guaranteed. Small text, logos, hidden construction and fit are not guaranteed. Human source comparison is required.

已有白马甲六张独立成片与两套 24 风格方向预览是历史样例，不证明 beta.11 的全部风格或新用户安装已验证。方向预览不是正式成片，不能裁成六张冒充独立生成。
Historical demos do not establish beta.11 visual quality or new-user success. Direction previews cannot be split into independent finals.

隐私与费用 / Privacy and cost

  • 插件无独立遥测、额外 API key、连接器或后台上传服务。 / No plugin telemetry, extra API key, connector or background upload service.
  • 上传到 Codex 的素材由宿主处理；另行授权后，原生图片服务处理参考图与提示词并使用账号额度。 / Materials supplied to Codex are processed by the host. Separately approved generation uses its image service and quota.
  • ChatGPT 网页路线需对本次素材上传单独授权；手动或自动转交均使用用户自己的账号。没有宿主浏览器工具时，插件不会安装它们。 / Web handoff needs permission covering the materials and destination. The plugin does not install browser tools.
  • 图片与任务记录留在用户选择的本地工作区，由用户选择删除；宿主端留存按账号和服务商政策执行，不能声称仅本地处理。 / Local outputs and task records stay in the selected workspace until the user removes them. Provider-side retention follows the host account policy.
  • 不要公开客户照片、私有提示词、凭据、账号、本机路径或完整日志。 / Keep customer media, prompts, credentials, account details, local paths and full logs out of feedback.

如何判断结果 / Result states

prepared：本地任务已准备，还没有通过文件校验的图片回执；不代表已经生成或已获生成授权。收到图片后仍须完成 QA 和用户验收。
A prepared task has no accepted image receipt yet. Preparation is neither generation nor permission; returned images still need QA and user review.

状态 / Status含义 / Meaning
gate-blocked / unclear-hold输入越界或需要清晰补图 / Invalid source or clearer input needed
recognition-ready已识别，等待选择与授权 / Recognition ready; awaiting choice and approval
style-conflict-hold需确认单一主风格 / Conflicting style choices need confirmation
prompts-only / preview-grid仅提示词或非成片预览 / Prompts or non-final preview
image-draft文件已生成，QA 或人工核对未结束 / Generated image awaiting QA or human review
image-ready完整组的 QA 和用户验收已关闭 / Full-set QA and user review closed
tool-blocked原生能力不可用，停止且不降级 / Native capability unavailable; stop without fallback

预发布分发不等于运行时风格成熟度升级，也不等于 production-ready。验收表用 pass / fail / not-tested 记录实际结果。
Prerelease distribution does not raise style maturity or establish production readiness. Record actual trial results separately.

升级、回滚与移除 / Upgrade, rollback and removal

已有版本：在独立解压且校验的新包目录，先运行 python3 install-local.py --replace 预检，再运行 python3 install-local.py --apply --replace。保留输出的源和 marketplace 备份，执行打印的启用命令并新建任务。安装版本增加 +codex.* 后缀是预期缓存刷新；原 ZIP 不改变。

For an existing installation, preview and apply with --replace, keep both reported backups, run the printed enable command and open a new task. The replacement version suffix is expected.

回滚使用输出的 source_backup 路径（替换下面占位符），先预检再应用：

python3 install-local.py --source "<reported-source_backup-path>" --replace
python3 install-local.py --source "<reported-source_backup-path>" --apply --replace

执行新的 Next: 命令；不直接用旧 marketplace 备份覆盖当前配置。 / Re-enable with the new printed command; do not blindly restore an old marketplace file over legitimate later changes.

回滚只恢复插件代码。保留图片、人物包、任务与失败账本；旧 beta.11 helper 不支持新版模特任务，不能用于数据降级或继续运行新版任务。保留兼容的候选助手用于核对。
Code rollback is not task-data migration. Preserve model packages, outputs and failure records; do not resume new tasks with incompatible legacy helpers.

移除启用状态：codex plugin remove threadtruth-studio@personal --json（以实际 selector 为准）。源目录、marketplace 条目、Codex 缓存、备份、ZIP 和图片不会一并删除；它们是不同层，需要清理时逐项核对。真实 Codex 生命周期仍需试用验证。
Removal leaves source, marketplace entry, cache, backups and generated files separate. Retain backups for recovery; review each layer before cleanup. Actual host lifecycle behavior remains to be tested.

遇到问题 / Troubleshooting

  • 校验失败：停止安装，重新取得同一预发布版的 ZIP 与校验文件。 / Checksum failure: stop and obtain the matching pair.
  • 找不到安装器：确认位于版本根目录，不是内部 skill 目录。 / Missing installer: enter the full release root.
  • 检测到已安装：使用带 --replace 的预检与备份流程。 / Existing source: use the replacement preview and backup flow.
  • 名字仍旧、未启用或新任务无法调用：记录宿主版本、简短报错和最后成功步骤；不反复重装，不手改全局配置。 / Old name or missing discovery: report versions and the last successful step; do not repeatedly reinstall or edit global config.
  • 没出图：首次指令本就不生图；确认风格并单独授权后才测试。缺额度或工具时不改用 API。 / No image: recognition intentionally does not generate; confirm choices and approve separately. No API fallback.
