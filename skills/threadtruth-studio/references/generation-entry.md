# 生图入口建议

在风格/模式确认后、生成动作授权前读取。入口选择与 A/B/C/D 模式、0/1/2/3 动作独立，不改变服饰识别、风格冲突、画幅、身份锚点、闭集计数或 QA。

## 选择顺序

1. **用户明确选择优先。** `codex_native` 指 Codex 内置生图，`chatgpt_web` 指 ChatGPT 网页内置生图。不得因样本推荐覆盖用户选择。
2. **未选择时保留 Codex 默认。** 推荐网页不等于切换网页。用户只说“继续/按原方案”且已有明确入口选择时，继承该选择，不重问。
3. **仅在用户问入口优劣或明确优先渲染/合成时给比较建议。** 已确认风格优先查 [本轮结果表](generation-entry-evidence.json) 的 `rendering_results`：有胜者时推荐对应入口；平局、缺失配对或未测风格保留默认并说明缺少明确依据。未指定风格的总体渲染咨询可先推荐网页，但实际选用仍为默认或用户已选入口；不得借此自动确认风格。
4. 用户优先商品保真、身份或风格准确度时，不借渲染票切换入口，也不宣称某入口保证保真。继续现有事实源与 QA 流程。

结果表覆盖 24 个注册风格：网页渲染偏好 11 个、Codex 7 个、平局 1 个、缺失 5 个。电商棚拍、北欧极简、职场通勤女装、老钱、美式学院、静奢、复古工装是本轮 Codex 胜出的样本；具体结果以 JSON 为唯一数据源。

可运行纯本地建议助手（无依赖、无外部动作）：

```bash
python3 scripts/recommend-entry.py --style italian-luxe --goal rendering
python3 scripts/recommend-entry.py --style office-commute-women --goal rendering --selected chatgpt_web
```

路径相对本 skill。`recommended_route` 是可告知的建议，`selected_route` 是用户选择或 Codex 默认；两者可不同。这个助手不检查工具可用性、不授权生成、不上传图片。无 Python 时直接按上述顺序及结果表判断，不新增运行依赖。

简短交互示例：“本轮意式奢华样本更偏好网页的光影融合；目前仍沿用 Codex。你也可以指定 ChatGPT 网页。”不要每次都插入必答入口选择题。

## 网页执行

用户选择网页时读取 [网页转交与自动执行](chatgpt-web.md)，使用统一任务记录。浏览器操作由可用宿主工具执行；未通过真实六图实测前标注 candidate，不宣传即装即用。

## 执行边界

- 继续遵守当前会话的工具可用性及动作授权。推荐入口不可用时说明限制；不静默切换入口、不把一个入口不可用说成所有原生生图不可用，更不能转 API、CLI 或第三方服务。
- 用户选择网页后，上传前确认授权覆盖本次素材和 ChatGPT 目的地；已明确授权则不反复确认。只使用用户指定/已授权的专用浏览器环境，不读取或复制凭证。当前环境无法操作网页时给出提示词与迁移指引。
- 网页也只用内置生图。服饰事实源、参考图顺序、look-1 身份锚点、每张独立生成、串行、尺寸核验和单次调用上限与 Codex 相同。`image_gen` 在流程中代表内置生图能力，不要求网页暴露同名工具。
- 一个闭集沿用已选入口；切换不重置已消耗调用数、不自动重发、不用失败作为自动切换或扩张额度的理由。结果未确认时先检查原请求，不能以重发试探状态。

## 证据适用范围

本地对照运行 `style24-web-native-20260924`：48 次请求、43 张原图、19 组完整配对，三个隔离上下文重复盲评。渲染主票为网页 11、Codex 7、平局 1；每风格每端仅一张，五组缺失不计平局。原始素材和私人执行记录不随 runtime 分发。

这些是特定素材、提示词及入口状态下的样本偏好，不是稳定风格胜率或模型排名。实际生图型号未核实，不归因于“2.5”；不宣称统计显著性、评审统计独立、保真保证、六图完整工作流已复测或成熟度升级。
