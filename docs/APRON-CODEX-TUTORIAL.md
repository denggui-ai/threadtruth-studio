# 在 Codex 桌面版用裁光：让自己的照片穿上真实围裙

这份教程教你在 Codex 桌面版完成一次服饰图制作：准备素材、调用裁光、确认方案、生成单张、检查人物与商品，再保存结果。示例商品是红黑细格小熊长袖围裙，风格是日系生活感。

裁光负责读取真实服饰、安排人物和摄影、整理生图要求，并检查返回的图片。图片由 Codex 当前提供的内置生图能力生成。需要可用的生图额度；安装 skill 本身不包含额度。

## 1. 准备并打开裁光

先按[项目安装说明](../README.zh-CN.md)安装裁光，在 Codex 桌面版新建聊天。安装位置、插件版本和技能入口以你实际使用的版本为准。

在技能选择器里选择裁光，或在消息中输入 `$threadtruth-studio`。如果找不到技能，先检查是否安装、启用并已重新打开聊天；不要把“能输入名称”当作已经加载成功。

本教程依据 2026-10-17 本地安装的 beta.13 开发版实际操作整理。它包含后续本地更新，不表示所有公开 beta.13 安装包都已具备同样的真人参考与任务恢复能力。本文是用户操作教程，不是录屏，也不宣称所有机器上的结果一致。

## 2. 上传商品图和自己的人物照片

最低需要一张清楚的真实服饰图。希望沿用自己的人物外观时，再上传自己的清晰照片，并明确授权。

![本教程使用的小熊款围裙真实正面](tutorial-assets/apron-source.jpg)

本案例只有小熊款的正面。另一张兔子款正背面属于不同商品，不能用来推断小熊款的背面。没有实物资料时，不填写价格、材质成分、防水等功能。

人物照片的作用也要说清：只参考脸和发型，还是包含身体外观。近脸照和上半身照片不能证明真实全身体型或尺码。本次提供了近正面和两个侧向的人物照片，实际单张选用近正面主参考与朝画面左侧的侧脸参考；其余照片保留，不必每次全部加入请求。

下面是可以复制、替换的输入示例，并非本次聊天的逐字记录：

> 请用 $threadtruth-studio 核对素材。商品只采用小熊红黑格围裙，兔子款不要混用。人物照片是我本人，我授权用于本次生成；只沿用我的脸、发型和妆容，不沿用照片里的白衣服、话筒、首饰和背景。请先核对现有照片能支持什么，给我一份方案，暂不生成。

仅上传照片不会自动生图。裁光应先区分商品与人物参考，再说明已有素材能做什么、缺什么。

## 3. 用一份方案确认人物、风格、画幅和张数

本案例采用的方案：

| 项目 | 本次选择 |
|---|---|
| 商品 | 小熊红黑细格长袖围裙，只展示有正面资料的范围 |
| 人物 | 沿用本人已授权照片的可见面部、发型和妆容 |
| 风格 | 日系生活感 / Japanese Lifestyle |
| 环境 | 暖白、原木、侧窗自然柔光的居家空间 |
| 动作 | 身体轻微侧转站立，手避开小熊和大口袋 |
| 头部 | 朝画面左侧的窗边，使用已有对应侧脸资料 |
| 搭配 | 燕麦色长裤、无标浅色闭口鞋，无新增首饰 |
| 输出 | 一张独立 2:3 竖版全身图 |
| 次数 | 本次生成 1 次，失败或不满意不自动重试 |

真人全身图的脸部像素较少，目前不能承诺严格还原本人。只有脸部或上半身参考时，完整身材表现是生成安排，不是实测身体重建。若优先看人物像不像，可先提出更近的取景；这会影响围裙下摆等商品部位是否能展示，应在方案里一起确认。

如果方案符合需求，可以这样回复：

> 按这份方案在 Codex 内置生图生成1张，允许消耗1次生图额度，不自动重试。保留围裙的细格纹、浅色领口包边、长袖收口、小熊图案、大口袋和浅色口沿，不要把围裙改成裙装，不编造背面。

如果从一开始就给出了完整方案与对应授权，裁光可直接执行，不需要重复确认。只说“选日系”并不等于授权生图。

## 4. 生成时用户需要做什么

确认后，裁光整理实际提示词和参考图，调用 Codex 的内置生图。你不需要打开 ChatGPT 网页、复制英文提示词、运行终端脚本或提供 API Key。

等当前请求返回。若出现错误或不确定是否提交成功，先让裁光检查原请求；不要连续发送同样指令。下载或保存失败时恢复同一张图片，不应因此重新生图。

一张正式独立图、一个六宫格方向预览、六张独立图是不同的任务。当前只授权1张，不会自动变成6张。六宫格只能帮助看方向，不能裁开后充当6张独立成片。

## 5. 出图后分别检查“人”和“衣服”

图片返回后，让裁光展示原图、实际尺寸，以及会影响使用的问题。用户也应对照源图检查：

| 核对对象 | 重点看什么 |
|---|---|
| 人物 | 脸型、眼鼻口比例、表观年龄、发型和妆容是否符合原照；侧脸是否自然 |
| 围裙轮廓 | 宽松直身、衣长、领口、长袖和袖口是否改变 |
| 图案与结构 | 红黑格纹密度与方向、小熊的位置和形状、大口袋与浅色口沿 |
| 构图与人体 | 围裙下摆是否展示、手有没有挡住商品、手脚和头颈是否自然 |
| 摄影 | 是否有柔和侧窗光、暖白原木环境及空间层次，商品颜色是否偏移 |
| 文件 | 实际比例和像素是否与本次约定相符 |

“人物好看”和“商品正确”应分别判断。明显新增、删除或改造商品结构，不能仅凭整体好看就通过。细格纹、微小图案或源图不清楚的部位，应与高清照片或实物比对。

你可以直接给具体反馈：

> 人物我接受，但小熊和格纹还需要对照实物，先保存这张，不再生成。

或者：

> 这张脸不像我，请先指出偏差和最小修正办法，暂不重试。

如果决定重试，再明确要改哪一张、改什么、允许新增几次。例如“只修正这一张的小熊位置，新增1次，保留旧图”。说不满意、保存结果或检查问题，都不会自动增加生成次数。

## 6. 保存、接受和结束

要求裁光把原始图片保存到本地，并告诉你实际文件位置和尺寸。不要用聊天截图替代原图，也不要拉伸、强裁或加边来掩盖比例错误。

当你确认人物与商品都符合需求，可回复：

> 我已对照商品原图核对，这张人物和围裙效果都接受；已知生成内容发布时需要按适用要求标识。保存这张，结束本次任务。

用户接受人物本身不等于商品细节已核实。本案例结束在单张，不自动续做其余五张。以后需要同商品六张组时，可再提出新增五张需求；能否续用首张、需要哪些原始参考和多少新增次数，由当前技能版本与已有任务记录检查决定。更换商品时重新提供当前商品资料。
