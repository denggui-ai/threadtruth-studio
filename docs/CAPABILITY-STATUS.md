## 状态如何读

- **已实现**：现有指令或工具可以执行；不是每次效果都可靠。
- **限定验证**：有真实行为或图像证据，只覆盖所列素材、环境及版本。
- **部分验证 / 未全面验证**：已有局部证据，缺少完整目标的验收。
- **仍未解决**：已有失败或明确限制，没有充分后续证据关闭。
- **不在当前范围**：当前产品不提供，不计为待补功能。

下表将实现与验证分开；不合成一个“完成百分比”。历史报告里的未安装、缺素材等状态须结合后续记录读取，不倒填历史结论。

## 真正仍未完成的部分

| 缺口 | 当前事实 | 后续应如何判定完成 |
|---|---|---|
| 严格原真人还原 | 入口对照与补参考未证明普遍解决；固定母图保护不能替代 | 有明确新方法、实际结果与用户分项验收；不靠多抽图宣称可靠 |
| 自由姿势中的同人连续性 | 有AI、母图及同款近正面两种坐姿的有限接受，无通用保证 | 对实际新品与姿势独立核对原人物；尚缺完整六图、真实多角度、跨商品及全风格验证 |
| 商品结构与细节保真 | 历史有配饰遗漏、纽扣可见性、局部结构及伪影问题；M1仅关闭本次单张 | 对实际订单逐项核源图，关闭具体硬错误；满意不覆盖已知错误 |
| 当前简化流程的完整使用体验 | 规则与安装完成，完整新版模型会话验收未完成 | 实际新会话覆盖所需旅程；维护队列不是自动开启的新工作 |
| 外部环境与自然语言发现 | 本机显式调用不能证明隐式触发与新机器 | 独立环境真实安装与调用记录，不用模拟home代替 |
| 稳定版与广泛商用可靠性 | 目前公开的是beta.12预发布，不是稳定版 | 达到项目自己的Beta退出与实际验收条件，再单独发布稳定版 |

这些是现状缺口，不是本次自动开启的开发、生图或发布计划。下一次实际订单应先选具体商品、人物包及用途；在已有证据不能回答问题时再制定最小验证范围。
