# 裁光九张姿势编排：实施契约与审计处置

2026-10-29。用户已明确实施本方案。它替换此前“固定六母版先接图、以后扩九张”的设计；Git历史和原始审计证据保留。当前为源码开发工作包，实图、安装与发布不在本次授权内。

## 用户能力与缺证

新人物／不露脸套图默认九张，由服饰事实、用途和素材覆盖决定动作；经典六姿势可选，明确单张／六张照办。用户关心不同服饰选择合适动作、同组自然且有用途的变化，不是新增三个位置。

当前MASTERS序列和编号校验证明规划空间受固定六动作限制；不能据此断言实际图片雷同的唯一或主要原因。历史已出现头眼改善而肩胯动作不足、景别正确导出但成图仍失败。计划、链路和图片表现分别验收。

目标是复用已有识别、人物、摄影、冻结、账本、生成和QA能力；不新增商品识别系统、人物包、生成服务、状态机或风格姿势库。

## 实施契约

### 服饰驱动规划与职责

运行说明以references/pose-planning.md为唯一详细决策入口，复用recognition的部件／视角依据和既有用途分流。每张有展示或使用目的，选姿检查遮挡、受力、支撑、幅度、真人头向范围；各张不必全身，也不必不同动作族，但不能用局部图满足用户明确九张全身的要求。商品信息、身体动作、头眼和摄影变化分别判断。

shot_plan v2保留完整逻辑looks，使用slot与稳定shot_id，selected_shot_ids选择本次执行项；series_role区分standalone、series-first、series。逐张内容包含display_goal、must_show、reason、body_action、hands、support、framing、garment_views、商品reference_sha256s及可选pose_reference；AI露脸head/gaze成对提供。身体不再由序号或MASTERS推导。

shot_plan管身体，real_face_plan管真实头向／目光／脸可见性／身份覆盖；其身体描述由同一shot编译并核一致。visual_plan管摄影，不获得另一套动作权威。预览与独立图从同一冻结计划确定性编译，不临提交重新编排；修订保留旧版本、输出、QA与次数。

### 九张链路与兼容

新人物／不露脸默认9，支持明确1／6；经典六姿势用v1，非人像仍六构图，固定母图换衣和人物诊断依原专门流程。统一创建、校验、预览、承接、导出、续图、重试与交付计数。

完整系列始终留存；预览第七格抽取即使本地为look-1也保留原shot_id和slot，标standalone，不自动续八。只有真正series-first在首张接受、人物确认、原系列与必要条件保持并获得新增N−1次授权后续组。旧v1母版1续五、历史提示词字节与合法操作不静默迁移。

新默认一次3×3预览，再九次独立请求；两阶段授权分别记录，默认数量不授予十次调用。串行、首张确认、画布、未决恢复、失败证据及累计次数沿用。v2未通过的非锚点单张可修必要动作／景别／参考；无人物确认和下游依赖的独立单张也可修，不因文件名look-1误当系列锚点。其他已接受项及共享事实不动；首张身份锚点变更走原专门流程。

### 可替换参考层

资源anhao/ai-pose-gallery-zh的固定研究快照为072a3690af6e7e0011abbe0fa1ccc08939fbb47d：2899文件、1439条、288动作组，所有原图／缩略图成功解码；人工审阅全部288组代表缩略图及8组五视角，不冒称全部高清人工验收。数据主要是多机位普通图片，无现成骨骼／关键点／3D；商业自然动作覆盖有限，名称须逐视图核对。

LICENSE、README与页面整理的原站许可存在冲突，当前源固定research-only；不进入任何生图角色，不随runtime分发。自有或用途授权清晰来源可经同一接口使用。不能更换角色绕过图片来源门禁；转文字／骨骼本身不证明素材权限已清晰，一般身体动作仍可按商品事实独立文字规划。检查不能声称识别无来源声明的任意改名／修改图片。

pose_catalog按来源／组／视图进行轻量本地检索；只审核实际选用小集合。库存pose-reference使用pose_source={source_id,group_id,view,usage,note}，usage为owned／authorized／research-only；逐张pose_reference={sha256,reason}至多一个主参考。冻结来源与哈希，生成时不读取实时图库。来源声明不是自动权利核验。

创建、修订、续图、重试和导出共用按当前shot解析的实际有序附件，不能把全部非商品参考灌入每张。必要商品／身份／首张锚点均不能被姿势图挤占；当前原生实现五附件，其他入口按实际能力。自动建议图超容可在冻结前明示转文字，用户指定图不静默省略。

首版九格预览使用冻结动作文字与必要商品／人物参考，独立图才携带本张姿势图。不制作九图参考板；用户明确要求预览用指定图时先核能力，不能暗中降级。

## 验证与停止条件

源侧四类用例：胸前印花上衣、有正背依据阔腿裤、后中开衩长裙、独立披肩层叠服饰。扰动：去掉背面依据；要求九张全身。核选姿理由是否来自已知商品、用途或覆盖，不要求不同衣服动作清单完全不同。

代码回归覆盖：旧v1导出／恢复／续图兼容；九张完整链路；第七格抽取与单张误续组；图号／人体／真人覆盖／实际附件映射；姿势图串图和research-only拦截；超限不丢必需证据；单张修订不改其他已接受项；预算与未知恢复不重置。沿用现有测试与源侧评估结构。

二十次实图建议为两件商品各1次九格预览＋9次独立图，只能说明这两例在当前条件下的可行性。须另有对应生成授权，全部初次输出、失败和次数保留，重试另记不自动增加。若声明规划增益，再做同条件旧六张与新编排六张对照；默认产品仍九张。若声明图像参考增益，固定同一计划，只改是否加入合格参考。无图无结论，不以计划完整、哈希通过或审查意见一致代替实图。

本包源码与离线验证完成即停止，不自动安装、发布或开展新的外部模型调用。代码问题按实际回归关闭；素材适用权限和图像效果保持open。验证结果另写源侧报告，不在runtime加入开发证据或改写历史失败。
