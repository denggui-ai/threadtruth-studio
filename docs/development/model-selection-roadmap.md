## 1. 原始目标与收口标准

让用户选到适合当前服饰和用途的人，并能在后续商品、后续对话继续使用这个人。用户不需要理解脚本、填写完整问卷或管理数据库。

| 用户情境 | 必须交付的行为 | 完成判断 |
|---|---|---|
| 已有品牌真人或 AI 模特 | 区分沿用身份与审美借鉴；保留原始人物依据，明确可见范围 | 不另选人，不臆造未知身体，不静默替换原身份 |
| 只有服饰图，没有模特 | 主推及两个有实质差别的方向、适配理由、可改因子 | 推荐基于商品与已知用途；建议不伪装成用户已确认事实 |
| 选定方向，希望看效果 | 经授权试拍首张，展示人物因子并等待实际人物确认 | 技术 QA、人物选择、商品商业验收分别记录；拒选可修订 |
| 继续这一组或展示新品 | 同组保留首张和累计次数；新品使用新商品事实并核对原人物 | 不把旧衣服、背景或未接受新图变成长期身份依据 |
| 换对话继续用她 | 私人参考包：原始参考、人物卡、确认范围与完整性信息 | 按用户指定位置读取，能解释固定与可调条件，不承诺自动记忆 |

完成目标是“可选定、可复用、漂移能被发现并停止传播”。不承诺像素级真人复制、真实身体测量或尺码合体。选人好看、人物一致、商品忠实均需分别判断。

## 3. 模特因子如何交付

沿用已有三列因子卡和现有 `factors` 数据，不先扩展 schema：**条件/值、状态、来源**。状态区分建议目标、已确认固定、允许调整、未知；来源区分用户要求、参考可见、系统建议。选择前给方向卡，首张展示时核对实际表现，接受后保存人物卡。

| 因子 | 用户应知道什么 | 约束 |
|---|---|---|
| 面部、可见年龄感、肤色 | 当前身份参考和允许变化范围 | 年龄感不是精确年龄；不得从图推断国籍/民族 |
| 胖瘦、肩线、身体比例 | 参考可见部分与新提出的视觉目标分别列出 | 脸照不能证明身体；不虚构身高、胸腰胯或真实尺码 |
| 妆发、表情、气质 | 默认沿用什么、用户允许调整什么 | 长期允许调整不等于当前编辑可改；保护区涉及它时必须说明冲突 |
| 目标市场与审美 | 用户提供的市场背景和具体可见审美方向 | 市场/国籍不能简化为脸型，也不能由衣服推断真实客群 |

固定姿势路径属于明确选用的可选功能。它锁住既有姿势和受保护区域；要求换发型、表情、头部角度、身形或穿上与保护边界冲突的高领/帽子时，说明该路径无法直接满足，再让用户选择合适的任务方式。不能静默改身份，也不能把所有新商品都导入此路径。

## 4. 后续开发顺序

### D1 — 现有主线覆盖核对（已完成，无生图）

**输入：** 上表已有实现、测试、三项真实流程评估与后续代码 diff。先复用旧证据，再决定最小本地补验；不例行重跑全部测试或新开多轮代理。

**核对三条旅程：** 无模特的推荐/改因子/拒选；已有模特的 face-only 与造型调整；参考包跨商品/跨对话导入与当前首张确认。每条记录实际用户可见输出、进入提示词的条件、附件角色、确认状态及失败停止行为。

**输出：** 在本文件对应行补充覆盖结论，并在 `docs/verification/` 留一份脱敏核对记录；私人执行输出不入库。缺口必须指到具体文件/操作/证据，不把“没找到证据”直接写成“功能缺失”。

**停止条件：** 每条旅程均能判定已有覆盖、确有缺陷或具体缺证。没有确证缺陷就不加代码，直接进入 D3。

### D2 — 只修 D1 证明的主线缺口

每个修改绑定一个可复现问题，优先级为：选错人/丢失身份或商品事实 → 因子与实际提示词不一致 → 确认或恢复失效 → 用户看不懂交付。

候选改动位置只按缺陷选择：`references/model-selection.md`、识别/流程/QA 对应段、`scripts/model_reference.py`、`scripts/web-task.py`、`tools/style_preview.py`。不是要求这些文件全部修改。

每个行为改动同步源侧回归和 `CHANGELOG.md`；执行相应本地测试。进入安装候选前再做必要全量与打包核验。保留旧参考包读取、原六姿势、24 风格包、累计预算和已修 F1–F4。不重写整个系统。

**停止条件：** 已复现的问题消失，对应回归通过，声明范围清楚。仍有生图效果不确定时转 D3，不继续叠加工具来掩盖它。

### D3 — 利用已有图片完成范围验收，确实缺证才补图

先对齐原图、当前接受集、实际附件/提示词与用户决策，分别判断：选角适配、原人物相似性、候选连续性、商品事实、姿势覆盖。人工有限接受不自动关闭商品失败；自身母图零像素变化不升级为原真人还原。

若必须新生图，先明确一个无法用现有证据回答的问题、相关改动或输入差异、成功/失败标准、所需最小次数及失败后的停止点。取得对应授权后才执行；不得自动续成六张、重启整套 14 张实验或增加重试。仍无改进依据时报告能力限制，不无限重复。

**停止条件：** 原目标各项有范围明确的通过或未解决结论。用户要求更广的真人保真研究时另立范围，不把该研究混入当前收口。

### D4 — 有新版本才交付，无新版本就结束

只在 D2 产生实际改动时准备增量发布、回滚和指南；沿用相应安装授权边界。已有版本安装完成不构成再次打包安装或生图的理由。最终交付一份简短能力/限制说明与可用参考包位置，声明哪些需要人工介入。
