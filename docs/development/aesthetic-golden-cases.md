# 审美黄金案例门禁与规则预算

本文件是开发验收流程，不进入技能运行文本。适用于改动规划层（取景、选姿、动作池、风格卡、提示词编排）以及每次发版前。

## 一、黄金案例门禁

**固定三个案例**（同一商品依据，9 格 2:3 方向预览）：

| 案例 | 输入 | 当前基线图（盲审胜出版本） |
|---|---|---|
| 度假 | P3 花卉连衣裙挂拍 × `resort-vacation` | E3b（`bf14b13`） |
| 旗袍 | P13 黑旗袍两张上身图 × `qipao-urban` | E4（`982bec6`） |
| 法式 | P3 花卉连衣裙挂拍 × `french-effortless` | A2（`d7d7e66` 前的 10-29 版） |

**流程**
1. 用改动后的版本为三个案例各出 1 张（需 Owner 授权额度，默认 3 张）。
2. 新会话盲审：与基线图混排、随机编号、对应表另存不给审查方；按"身体动作与支撑、情绪跨度、人物在画面中的大小、场景、衣服保真（印花、版型、长度）、风格辨识度"逐格比较，最后解盲。看图审查用 Codex，不用 DeepSeek。
3. **判定**：三个案例都不差于基线才可合并或发版；任一明显变差 → 不合并，先报告证据。新图胜出时，替换为新的基线并在上表记录版本。
4. 每个版本只有一张样本，盲审结论要注明"单样本，不排除生成运气"；结果不明确时，每案例补 1 张需 Owner 另行授权。
5. 画面是否通过由 Owner 定；脚本检查和摘要一致不能替代实图验收。

**零生图的前置检查**（出图前跑，任何一项失败先修）：全量测试只剩已知环境失败；旧冻结请求摘要（`tests/test_aesthetic_legacy.py`）不变；新规划的 `framing_guidance` 为 3、提示词不出现 "Camera far back"。

**例外记录**
- 2026-11-04 PR #70（人物格 `must_show` 可空）：未跑本门禁，按 Owner 当次指定验收——花裙 P3×波西米亚、婚纱 P14、旗袍 P13 各 1 张对比标准照、只看图。花裙更多样、婚纱不差但偏正面；旗袍 3 次在生图前被既有 JSON 校验拦下未出图（main 对照出图）。下次规划层改动或发版时按本门禁补跑三例。

**规则**
1. 合计上限 131,230 字节，不再提高。新增规则须在同一提交里删除或合并等量文字；提交说明写明增删字节。
2. 新规则优先写成文字建议，而不是脚本里的硬拦截。确需硬拦截时，必须同时写明它对已有任务的适用范围。
3. 发布前老任务只保证原请求原样续用；重新准备或修订出问题，在文档里写"请按新任务重新开始"，不为此加兼容代码。
4. 缩减体量（把旧任务兼容文字移出必读、合并冲突条文，目标必读 ≤60K）列为 M 阶段之后的 Q5，不在本门禁内强制。
