## 视觉验收

先记录硬失败，再记录分项分数。服饰硬事实、身份、姿态、缺失视角、文化形制、数量与画布任一必要项失败，不能用摄影好看或平均总分抵消。

| 维度 | 需记录的可观察证据 |
| --- | --- |
| 服饰保真 | 轮廓、开合、领袖、褶量、层次、颜色、纹理及明确可见细节逐项对源；未知面不得补事实 |
| 身份 | 同一声明人物来源、脸型与主要外观；真人是否严格使用指定源且朝向有依据 |
| 姿态 | 身体方向、头向、视线、手位、前倾幅度分别记录；不以标签“自然”代替观察 |
| 整组变化 | 六张是否存在有意义且合乎人体结构的头向/视线变化；不强制六种夸张转头 |
| 风格可见性 | 当前方向卡的具体视觉信号是否可见，能否与近邻方向区分；不只看同名标签 |
| 摄影与展示 | 主体清楚、服饰可读、光线/场景/构图服务目标；人物以外的展示方式不补脸 |
| 文化/年龄边界 | 道袍形制不混代；旗袍开合与滚边不改；工布不被泛藏袍替代；儿童不成人化 |
| 交付事实 | 实际独立文件数、唯一输出哈希、实际像素与比例、编辑目标版本、调用次数可核对 |

分项建议使用 0–4：0=明显失败，1=多处问题，2=基本可用但需修正，3=符合要求，4=有清楚可说明的优点。原始分数、失败部位和审核意见全部保留；`not-applicable` 与 `not-observable` 单列。预览只能评场景、色板、宽泛搭配与镜头方向，不能升级为身份/商品细节验收。
