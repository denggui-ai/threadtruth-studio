# 日系家居：从真实商品图到六张独立服饰图

本教程使用茶绿针织开衫案例说明裁光的完整流程：核对素材、确认方案、验收首张人物，再完成其余独立图片。适用于具备原生图片生成能力的 Codex；生成会消耗订阅额度。

**版本范围：** 案例于2026-10-07在全新对话中运行，原安装版生成前四张，隔离流程修复候选完成后两张。2026-10-08的开发源码已整合该修复，并补充动作、搭配和坐姿展示规则；公开 beta.12 下载包与既有安装未更新。新增画面规则尚未进行生图复验，不能把本案例写成更新后版本的视觉验证。

## 1. 准备商品与人物参考

至少提供一张清晰的真实服饰图。正面、前侧和细节图有助于识别颜色、门襟、袖口和衣摆；要展示背面，需要真实背面资料。

本案例使用两张商品图，其中第二张有两个色款，只采用右侧茶绿开衫。商家模特的脸、原图首饰和另一色款不属于本次人物或商品要求。人物由用户提供的已授权参考包决定。

| 素材 | 用途 |
|---|---|
| 当前商品图 | 商品颜色、结构、长度与可见细节的事实依据 |
| 原始人物参考 | 用户授权沿用的面部身份；忽略旧服装、姿势与背景 |
| 已接受的面部补充图（可选） | 辅助人物延续，从属于原始人物参考 |
| 本组实际首张 | 确认后辅助后五张的人物延续；不替代商品图，也不固定后续姿势 |

新对话需要重新提供素材，或明确给出可访问的本地参考包位置。旧图满意不会自动成为新组的首张确认。

## 2. 一次说清风格、搭配、数量和画幅

可以直接使用下面的需求写法，替换为自己的真实素材与权限说明：

> 使用裁光。商品图只采用我指定的茶绿色款；人物参考已获得肖像使用授权，沿用该人物，保留原表情与发型。我要日系家居，柔和窗光、原木和燕麦色环境，开衫搭白圆领T、米色直筒裤与白色闭口鞋。六张独立全身图，1024×1536。第3张坐木椅，第5张坐沙发前沿微前倾，门襟与衣摆要清楚。没有背面素材，第6张改为正面自然站立。先核对素材并给完整方案，暂不生成。

裁光核对后给出一份方案。确认该方案及六次调用预算即可；也可以一开始明确“按上述要求直接生成6张”。本组按顺序逐张生成，先展示首张供人物确认。不能将六宫格预览裁成六张交付图。

本案例的动作计划如下。家具可以按需求选择，沙发不是所有日系图片的必需道具。

| 图片 | 身体动作与场景 | 商品展示目标 |
|---|---|---|
| 1 | 窗边侧身回转站姿 | 保留有依据的正面与前侧范围 |
| 2 | 暖白墙边倚靠 | 倚墙支撑可辨，避免只换背景 |
| 3 | 原木椅端坐 | 全身取景；手臂避开门襟与衣摆 |
| 4 | 客厅正面轻步 | 迈步动作可辨，避免衣物被遮挡 |
| 5 | 沙发前沿微前倾 | 前倾与沙发支撑可辨，区别于端坐 |
| 6 | 正面自然站立 | 缺背面时的明示替代，不编造背部结构 |

“全身”表示避免画框截掉需要展示的部位，不自动要求行走时两只鞋永远分别无遮挡。若鞋是待售商品或要求两鞋无遮挡，应在方案里明确。

## 3. 首张确认后继续剩余图片

首张生成后先核对人物、商品和实际尺寸。人物符合需求、商品没有明确硬错误后，用户确认本组首张人物；其余五张沿用原剩余授权继续，不逐张重复确认相同预算。

后五张始终携带商品事实源与原始人物参考，并使用本组确认首张帮助人物延续。首张用于身份，不用于复制每张的倾头、视线、身体姿势或背景；保留表情、发型也不等于冻结头部角度。明确采用固定姿势母图的局部换装任务另按其保护边界执行。

鞋包属于本组已选搭配时，把首张中清晰可见且已接受的款式特征写入后续提示词；只写“白鞋”不能保证鞋型一致。看不清的细节保持未知，搭配不自动写入人物包或继承到下一件商品。

生成与检查在后台连续进行。完成后集中展示独立图片、实际尺寸及影响使用的问题。

## 4. 这次真实测试得到什么

本次六次原生调用得到六张独立原始PNG，实际均为1024×1536，文件各不相同，没有额外生成重试。人物、茶绿开衫、白T、米裤和暖光家居氛围整体连续；木椅与沙发坐姿都有。

实际限制也应保留：几张站姿的差异偏小，头部倾斜与视线相近；白鞋具体款式未完全统一；第3、5张局部遮挡下部门襟，第5张衣摆也未完整展示。细微针织、扣位及源图不可见结构仍需对照实物或高清资料。首张人物已确认，最终整组商品验收尚未记录。

因此，这是一组可供审阅的生成结果，仍为 `image-draft`，六张均有 `qa-user-review`。六张返回、内部技术接受和用户商用验收是不同事实。

## 5. 中途问题怎样处理

这次第4张轻步中的后脚自然被前腿遮住，最初被误判为必须重生；执行工具又要求全部前序图通过，阻断第5、6张。用户批准隔离修复后，保留旧图、原判与调用记录，复核第4张，并修改尚未生成的第5张为沙发前沿微前倾。两项操作未增加或清零调用次数，随后只使用原剩余两次完成全组。

当前开发版的处理原则是：

- 已完成评定的非首张视觉问题只影响该图与最终验收，可以继续其他已授权编号；失败图不会自动成为合格交付。
- 首张身份失效、未知或未结束请求、服务失败、损坏返回和尺寸错误仍会暂停。未知请求先检查原结果。
- 原QA标准用错时重新评定同一原图，保留旧判与理由；未提交的计划可版本化修改，不改写已调用提示词。
- 新增生成重试仍需具体授权。保存恢复不等于重新生成，不重置预算。

原隔离候选通过17项本地回归，并完成一次真实两张续跑；源码整合后的验证范围见[开发验证记录](https://github.com/denggui-ai/threadtruth-studio/blob/main/docs/verification/2026-10-08-japanese-home-optimization.md)。本地模拟故障不冒充真实图片服务故障，新规则不冒充新的图片质量证据。

## 6. 最终接受与公开使用

最终反馈应对照六张和真实商品，说明哪些图片接受、哪些细节仍待核对。用户认为人物好看不能关闭明确商品结构错误；源图不足也不能写成已经核实。

本教程只公开操作文字与脱敏测试结论，私人肖像、商品原图和生成图未纳入公开仓库。公开展示图片须先明确对应素材的使用权；生成内容的发布标识要求见[使用指南](../README.zh-CN.md)。
