版本：`1.0.0-beta.11+compact.20261005`。源码状态为 **candidate**；简化交互运行文件已完成维护者本机安装核验，尚未发布对应的公开下载包。GitHub 源码同步不等于 Release 发行。

本次增量默认只给一份人物、风格、用途与数量方案，一次明确确认后执行；已授权条件直接沿用。图片优先展示，单张满意后结束；完整目录、备选和详细QA按需展开。准备状态、首句核对、人物确认和风格读取修订继续保留。没有有效图片回执的本地任务显示 `prepared`；已有图片仍是待验收草稿。已有人物默认妆发修复保留。本批不新增生图，不能据文字与工具测试推断保脸质量提升。

## 两种姿势路径

- **新建六张搭配图**：正面/前侧素材足够但缺背面时，明示把第六张改为静止正面站姿，保留前五张；不从 AI 人物图补商品背部事实。明确要求背部或原六姿势不变时，先补真实素材。
- **选定母图局部换装**：按已选母图的实际姿态编辑。上面的替代规则不授权换掉母图或改变保护区；新品素材不能支持母图可见结构时，补素材或由用户明确另选受支持母图。

两条路径都保留商品 QA、人物确认、独立生成授权与累计调用次数。人物确认不是商用验收，也不会增加生图预算。详见[模特复用指南](MODEL-REUSE.md)。

## 安装前

本机验收目标为 macOS 与支持个人插件安装的 Codex。参考包校验需要 Python 3 与 Pillow；固定姿势局部换装另需 Node.js 与 sharp。缺依赖会停止对应流程，不自动安装。工具仅本地校验/记录；真实生图需另有明确指令和账号图片额度。

仅在取得与本版本一致的构建 ZIP 和 `.sha256` 后执行下列步骤；本次源码 PR 不提供公开 Release 下载。保留完整旧版源备份；官方更新可能清除旧缓存。校验值应通过可信渠道核对，它不单独证明发布者身份。

```sh
shasum -a 256 -c threadtruth-studio-1.0.0-beta.11+compact.20261005.zip.sha256
unzip threadtruth-studio-1.0.0-beta.11+compact.20261005.zip
cd threadtruth-studio-1.0.0-beta.11+compact.20261005
python3 install-local.py --replace
```

逐条执行；上一条失败立即停止。最后一条是预检，不写入。本地候选不能通过公开 beta.11 Release 下载获得，不能混用两个版本的校验值。

## 已授权替换后

确认预检的路径和替换范围后，执行：

```sh
python3 install-local.py --apply --replace
```

它备份原源目录与 marketplace 文件，在用户主目录的 `plugins/threadtruth-studio` 登记候选，并保留其他插件记录；它本身不启用插件。保留输出里的备份位置，执行其 `Next:` 后的完整 Codex 命令。替换时版本可能变为 `1.0.0-beta.11+codex.<时间>-<标识>`；安装器会改写构建标识，因此须同时比对运行文件 SHA-256，不能只看版本名认定包含修复。

启用后开一个新的聊天，以便重新加载技能。先做无图片、无生图的发现检查：

```text
请用 $threadtruth-studio 说明已有人物参考包如何用于新品，
缺背面时如何安排第六张，以及选定背身母图时能否自动换正面。
不要生图，不要读取任何个人照片。
```

预期区分新建六图计划与固定母图编辑，保留首张人物确认、商品源优先、原始身份参考和单独生成授权。此文字检查不证明图片效果。完整六张/真人保真/商用效果必须单独实测和验收。

## 备份与回滚

保留图片、人物包、任务目录和失败账本。源代码回滚不等于数据降级：旧 beta.11 helper 不支持新版模特任务，不能用旧助手续跑或抹去这些任务；可保留独立候选副本用于兼容读取。

在当前已解包目录中，以实际备份路径替换占位符，先预检再恢复：

```sh
python3 install-local.py --source "<reported-source_backup-path>" --replace
python3 install-local.py --source "<reported-source_backup-path>" --apply --replace
```

随后执行本次输出的 `Next:` 命令，并开新聊天检查。不要拿旧 marketplace 备份覆盖后来新增的其他插件记录。移除启用状态不删除源、缓存、备份或私人输出，清理应另行逐项核对。
