# ChatGPT 网页使用流程

[beta.8 预发布版](https://github.com/denggui-ai/threadtruth-studio/releases/tag/v1.0.0-beta.8)已提供手动转交与由宿主工具驱动的自动执行。维护者 macOS 与专用 Chrome 环境已完成自动六图和单张转交包自动化验证；真人完整手动试用、其他宿主与操作系统仍未验证。安装插件不会同时安装浏览器工具；没有这些工具时可按[操作教程](CHATGPT-WEB-TUTORIAL.md)手动转交。

## 如何开始

上传真实服饰图后说：

> 请用 $threadtruth-studio 识别服饰，确认风格、画幅和方案。我选择 ChatGPT 网页内置生图。先不要上传或生图。

核对方案后明确允许本次素材上传到 ChatGPT，并选择先测一张或生成一组六张。重复授权不是必需步骤：已有清楚授权则直接继承。

- 自动执行：用户自行登录专用 Chrome；Codex 检查浏览器是否支持上传及原图下载。一次只提交一张，记录原对话，再下载检查。
- 手动执行：Codex 给出编号图片、提示词和说明。按顺序上传到持久的新对话；先让 Codex 记录即将提交的编号，再点击发送一次；下载原图并传回 Codex。
- 无可用浏览器工具时仍可做手动流程。不要把浏览器调试端口或本机目录当作所有用户必备配置，不复制主浏览器登录凭证。

## 六张如何保持同一人物

第一张使用服饰源图生成新 AI 模特。检查服装、人体、身份和尺寸后，后五张各自使用同一组服饰源图，再追加已验收的第一张作为身份参考。上一张未落盘或未通过检查，不会继续下一张。

## 卡住时如何处理

告诉 Codex“恢复这组任务”，并提供原任务目录或对话。已发送但状态不明的请求先查原结果，不要再次点击发送。下载失败可手动提供同一请求的原图；尺寸不符、额度不足或身份锚点不合格会暂停。六个编号完整并不等于商业验收完成。

## 文件与隐私

任务目录包含服饰副本、哈希、提示词、用户授权摘要、ChatGPT 对话地址、输出和进度；只保存在用户指定工作区。上传到 ChatGPT 后遵循账号与服务方政策；本工具不控制服务器保留期限。任务记录和客户素材不能直接发布到 GitHub。仅使用内置生图，无 API key、第三方生图服务或遥测。

## 首张不合格时

不会自动重试或继续后五张。Codex先保留失败图、说明商品事实问题，并展示修正提示词和追加次数。你明确批准后，可在同一任务追加一次重试授权；旧记录和累计次数保留。首张重试通过才继续。状态不明的请求先找原对话，不能用此功能重发。已有一次六图验收记录不保证下一次重试或整组生成合格；每组仍须独立检查与验收。
