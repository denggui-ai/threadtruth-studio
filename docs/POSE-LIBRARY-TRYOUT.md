# 52动作／60视图 · 选姿说明

本页对应 **0.1.0-beta.2预发布版**：52动作／60视图、知识与风格规则、22卡动作池、跨组避重和推荐排序。沿用已核对的运行规则，本版只压缩既有线稿和调整分发内容；此前14／16候选的归档保留。[下载与使用说明](STUDIO-CANDIDATE.md)。

## 先看、再选，不消耗生图额度

1. 打开[选姿页](../skills/lookset/references/pose-library/index.html)，按服装和展示目的筛选。站、坐、走及地坐、跪姿、蹲姿、侧卧等均在同一目录。
2. 勾选动作及视图，填写要应用的图号，默认保留文字模式，复制选择文字回聊天。页面不会提交到聊天或自动开始生成。
3. 配合服饰参考说明：“用这些动作安排指定图号，其余你来安排。先展示计划，不生图。”代理核对商品可见面、活动余量、遮挡和支撑，再冻结逐张计划。
4. 只有明确要用姿势图片时才选附图；它占用一个参考位。商品和人物必需参考已占满时，不挤掉它们以附上姿势图。预览不默认附姿势图。

本库适配成人女装AI／新人物或成人不露脸任务。男装、儿童和未核真人露脸方向不属于这次图库扩展范围；它们沿用原流程。旧风格情节与新库共同供选择，不强制优先新库，经典六姿势和旧冻结任务保留。

## 想让代理推荐或避开上一组动作

在聊天中说明本张展示目标，并指出要对照哪些已有任务记录。例如：“重点展示领口，参考上一组任务避开重复，推荐几个动作并说明理由，先不生图。”推荐先看商品与人物范围，再参考精确／近似重复，保留每个动作的限制；不会自行改计划或附图。推荐沿用成人范围，男装仅用当前风格文字，儿童和真人新露脸角度仍走原流程。

22卡／176条情节已接入共享动作池，不等于新增176张图片。历史对比使用选定任务的冻结文字；近似仅覆盖有限英文身体、手位与支撑描述，不能看图识别姿势。缺历史或文字不足会提示，必要复用可说明具体用途。选姿页仍用于浏览和手动选择，推荐及历史比较在聊天准备流程中处理。

## 怎样读逐图限制

59图几何可参考（3图沿用试点判断），并非60图全部精确通过或商品效果通过。画风、体型塑形、边距与几何问题分别记录，使用前按当前商品核对。

**推袖R029/v4：右前臂仍遮腹，GEO-SLEEVE-01保持open。** 不能用于腰腹无遮挡或腰腹卖点展示。它不进入默认候选，自动选择会被拒绝；用户明确指定时默认仍为文字，明确选择附图才返回对应引用。文字和附图两种模式都须保留遮腹限制；不将明确附图一概禁止，也不把该图当作无条件通过。

线稿只提供动作、手位和支撑参考，不能提供未知商品背面、真实人物角度、身份或搭配事实。希望的展示目标与动作不相容时，先调整本轮选择，不靠线稿覆盖实物。

## 已验证什么

- 已有基础117项回归；扩库另有43项相关回归和12个实际prepare/init/export合成任务。旧定义保持，新增四类能传到请求，商品视角与主体边界仍有校验。这些集合有重叠，不汇总成一次全量通过。

已具备基于任务记录的精确／有限文字近似避重及候选排序；没有跨组历史数据库或全品类成片保证。浏览和冻结链路通过不代表生成结果满足要求；实际结果仍须对照服饰与人物原图验收。
