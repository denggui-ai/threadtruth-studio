# 姿势库本地候选试用

本候选 `1.0.0-beta.16+pose.20261102.cea56ea` 包含 **14 个基础动作、16 个视图**，用于成人女装 AI／新人物或成人不露脸任务。它增加看图选姿、复制回聊及逐张动作冻结；实际成片改善仍未得到证明。完整资产库的 52 动作／60 视图没有全部装入本候选。

## 先看、再选，不消耗生图额度

1. 解压后打开[选姿页](../skills/threadtruth-studio/references/pose-library/index.html)，按服装和展示目的筛选。
2. 勾选动作及视图，填写要应用的图号，默认保留文字模式，复制选择文字回到聊天。页面本身不会提交到聊天或自动开始生成。
3. 配合服饰参考说明：“用这些动作安排指定图号，其余你来安排。先展示计划，不生图。”代理会核对商品可见面、活动余量、遮挡和支撑，再冻结逐张计划。
4. 只有明确要用姿势图片时才选择附图；该图占用一个参考位。商品和人物必需参考已占满时，不挤掉它们以附上姿势图。

新库与原有风格情节共同供选择，不强制优先新库，也不默认逐张附图。经典六姿势和旧冻结任务保留原契约。男装、儿童和真人新露脸角度不属于本轮扩展范围。

## 校验与安装准备

这是本地试用包，未公开发布。使用与本指南一起提供的 ZIP 和校验文件，不替换成 GitHub 的 beta.16 包或自动 Source code ZIP。先进入保存这两个文件的目录，运行：

```bash
shasum -a 256 -c threadtruth-studio-1.0.0-beta.16+pose.20261102.cea56ea.zip.sha256
unzip threadtruth-studio-1.0.0-beta.16+pose.20261102.cea56ea.zip
cd threadtruth-studio-1.0.0-beta.16+pose.20261102.cea56ea
```

校验显示 `OK` 后才解压；使用空目录，保留原 ZIP 和校验文件。插件根目录应同时含 `.codex-plugin/plugin.json`、`install-local.py` 和 `skills/`。

本轮只准备候选，没有替换本机安装。实际启用应先检查 `python3 --version` 与 `codex plugin add --help`。已有版本使用 `python3 install-local.py --replace` 预检；核对来源、版本及备份位置后，再在已授权的安装步骤执行 `python3 install-local.py --apply --replace`。首次安装省略 `--replace`。运行助手输出的准确 `Next:` 命令，随后在新的 Codex 聊天确认安装版本和调用。

升级会备份旧源与已有 marketplace 登记，且安装版本会使用 `+codex.*` 缓存后缀；保存回执以对应本候选。回滚使用助手报告的 `source_backup`，按[安装指南的升级与回滚步骤](INSTALL.md#upgrade-and-rollback)预检、替换并重新启用。不要直接覆盖当前 marketplace 配置，也不要删除旧任务和失败记录。当前候选尚未实际安装、回滚或验证新机器发现能力。

## 验证范围与已知限制

- 源码的 117 项相关回归、独立源码审查及本地选姿交互已经完成；本地包另检查解包、资产一致性和离线选姿。它们验证链路，不证明画面更好。
- 6 例独立新旧规划的初稿盲评为 5 例相当、1 例旧方案更好；修订后运行检查通过，没有改写初稿评价。
- 同一商品的两种任务各比较旧文字、新文字、新文字加图，共 6 张，每条件一次。两份独立匿名看图意见在手部避挡任务均偏好旧文字；正面展示任务没有一致赢家。
- 六图均因顶部留白不符保持 `qa-retry`；包的左右位置也有偏差。商品细小结构及严格同脸尚未获人工接受，不能当商用通过。
- 当前没有全库自动迁移、跨组历史避重或全品类成片验证；推袖资产的遮挡限制仍留在完整资产目录中，该资产不在本候选内。

后续试用先确认选姿和计划是否符合商品目的。生图需要对应任务的明确授权；本说明不追加调用次数。反馈请记录版本、所选动作／图号和具体失败现象，私人图片与完整日志仅保留在本地。
