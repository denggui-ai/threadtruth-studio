用 ThreadTruth 在 ChatGPT 网页生图

本教程记录 beta.8 的网页转交流程。beta.8 已提供插件安装包；旧版不保证提供这里的转交包和任务记录功能。 请以下载版本自带说明为准。实测由自动化执行，不代表真人易用性测试。网页生图型号未核实，不承诺“2.5”。

以下步骤适用于已具备转交包和任务记录功能的版本；若当前版本不具备，请先在 Codex 请求“仅输出生图提示词”，自行在 ChatGPT 上传参考图并生成单张，不把自动执行或台账功能视为已安装。

先准备什么素材

单件与整套服饰都可用，最低一张清晰真实图开始识别，推荐补正面、背面与细节。见素材指南。先选一个主风格，再选单张或六张独立成片；24 风格不表示一次生成 24 组。六姿势、预览区别与生成指令在能力说明中。下面先以一张为例，网页上传与生成数量仍需明确授权。

1. 在 Codex 确认任务

上传自己的服饰图，输入：

请用 $threadtruth-studio 识别这件服饰。我选择 ChatGPT 网页内置生图，请先确认风格、动作和尺寸，给我编号参考图与提示词组成的转交包；先不要上传或生图。

确认方案后，明确授权对应图片上传 ChatGPT，并说明生成数量，例如“允许这些参考图上传 ChatGPT，先生成1张，不自动重试”。需要 ChatGPT 账户及可用的生图额度；请求会消耗账户额度。

2. 选择怎么执行

手动转交：在自己的 ChatGPT 登录账户中新建普通持久对话，按转交包编号上传参考图，完整粘贴该张 prompt.txt。只使用网页内置生图，不启用其他插件。本教程所描述的手动步骤经过自动化操作验证；尚未由真人完整试用。

Codex 自动执行：对 Codex 说“请自动执行已授权的这1张网页生图”。本次验证环境为 macOS Codex 桌面版与已连接的专用 Chrome。宿主必须提供网页操作、文件上传与原图下载能力，安装 ThreadTruth 本身不会安装浏览器工具。没有这些能力时使用手动转交。登录由用户完成，不交出密码或登录凭证。

3. 发送前核对

检查缩略图全部上传完成、编号顺序正确、提示词完整、生成张数与画幅正确。首张通常只带服饰源；套组后续使用服饰源和已验收的首张身份参考，顺序以转交包为准。

手动操作时先告诉 Codex“已经放好，尚未发送”，让它核对并登记这次请求，再按确认消息点击发送一次。自动模式由 Codex 在点击前登记。登记使用同一任务记录，切换手动/自动不重置次数。

4. 等待与下载

保留原对话，等待图片完成。点击生成图片打开预览，使用“下载”或“下载图像”保存原文件。网页界面可能不同，按当前可见按钮操作；不要用截图代替原图，不裁切、拉伸或锐化来掩盖问题。

若页面卡住、断开或不确定是否已提交，先回原对话查看。不要反复发送或新建同样请求。下载失败只恢复下载，不重新生图；无法确认时暂停。

5. 回传与验收

手动操作：将下载的原文件交回 Codex，并说明它对应哪张编号。自动模式：Codex 下载后记录原文件位置、尺寸和哈希。检查服饰结构、颜色、配饰、人物与空间合成以及目标尺寸。

首张通过后，才把它作为身份参考生成其余图片。失败不自动重试；重试须重新明确授权，原失败图和已用次数保留。只有文件下载成功不代表画质或服饰保真通过。

6. 本教程的使用范围

默认 Codex 生图；明确选择 ChatGPT 后才走网页。不同机器的浏览器连接与权限由宿主配置，不能承诺所有用户安装后都能自动执行。参考图和提示词会发往 ChatGPT，本地转交包与任务记录由用户保管。

分享使用反馈时，不公开个人账号、对话链接、浏览器句柄、私有路径或完整执行日志。本教程不附私人参考图、生成图片或执行日志。
