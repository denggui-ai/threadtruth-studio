## 本版可以怎样用

先提供有权使用的清楚服饰照片，说明用途；已有明确风格、人物和数量就直接沿用。只有正面时，在正面、前侧与局部范围内安排，不补造背部结构。人物／不露脸默认九张编排及九格方向预览；主动单张、明确六张、经典六姿势和只要提示词仍可选择。预览与独立成片的授权分别记录，预览不能裁开冒充成片。

**选姿：**在选姿页勾选动作、指定图号，再把选择复制回聊天。可只指定部分图，其余由代理按服饰安排。默认传动作文字；明确选附图才使用线稿，且不能挤掉商品和人物必需参考。52／60的接入范围为成人女装AI／新人物或成人不露脸；男装、儿童与未核真人露脸方向沿用原规则。[完整选姿说明](POSE-LIBRARY-TRYOUT.md)。

**修改拍法：**可以说“保留侧光与构图，环境改为暖棕，但衣服不改色”。代理应把选中的知识、修饰语和主辅风格写进本轮实际计划，同时修订相冲突的风格承诺；不会把整个知识目录塞入请求。商品事实、人物锁定和逐张动作优先。规则衔接已有编译与导出证据，尚无新会话稳定遵循或实际成片改善证据。

## 校验与后续安装准备

本工作包不安装。先在存放插件ZIP与校验文件的目录执行：

```bash
shasum -a 256 -c threadtruth-studio-1.0.0-beta.16+studio.20261102.569a9b6.zip.sha256
unzip threadtruth-studio-1.0.0-beta.16+studio.20261102.569a9b6.zip
cd threadtruth-studio-1.0.0-beta.16+studio.20261102.569a9b6
```

仅在校验显示`OK`后解压，使用空目录，保留原ZIP与校验文件。插件根目录应同时包含`.codex-plugin/plugin.json`、`install-local.py`、`skills/`及`USER-GUIDE.html`。

以后决定安装时，先检查Python 3与`codex plugin add --help`。已有安装使用`python3 install-local.py --replace`只读预检；实际替换须在获准的安装步骤中使用`--apply --replace`，保留旧源、缓存和登记备份，再执行安装器输出的准确`Next:`命令。首次安装省略`--replace`。当前资料不要求现在执行安装，也没有后台启用操作。

替换安装会产生`+codex.*`缓存后缀，须用回执与运行文件哈希对应本候选；升级后在新聊天核对版本，旧聊天不会热更新技能。回滚入口为安装器报告的`source_backup`，按[升级与回滚步骤](INSTALL.md#upgrade-and-rollback)恢复并重新启用；本候选没有新增实际回滚或新机器验证。

本包新增生图0、新模型评测0。后续每次生成仍需对应任务的明确授权；物料准备、方案接受和安装成功均不产生生图或发布授权。
